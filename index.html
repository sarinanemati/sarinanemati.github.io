Recommendation System Based on Your Persona

Live Demo (Streamlit)  |  GitHub Repository

Persona2Product is a context-aware recommendation engine built with Streamlit. It moves beyond standard collaborative filtering by matching users to products based on their shopping persona (e.g., Brand-Oriented, Budget-Conscious, Performance-Focused). The system leverages Clustering and an integrated Reinforcement Learning (RL) loop to refine recommendations based on user interactions (likes), creating a personalized and adaptive shopping experience.

Project Challenges

  1. Faced with a lack of pre-existing datasets for user shopping personas, I engineered a custom Web Scraper to extract raw product and user-interaction data from scratch.
  2. To overcome the lack of pre-labeled persona tags in the scraped reviews, I applied Unsupervised Clustering to automatically segment users and map them into distinct behavioral archetypes (e.g., Brand-Oriented, Budget-Conscious), laying the foundation for the reinforcement learning engine.
